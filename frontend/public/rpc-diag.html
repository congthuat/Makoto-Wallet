Makoto Wallet — RPC Diagnostic (read-only)

Identifies the injected wallet provider, checks chain ID and accounts, and measures response times for the exact RPC methods that precede Send/Swap/Bridge in production.
No write methods are called. No keys, seeds, signatures, or cookies are collected or sent. The official Arc Testnet RPC is queried as an independent baseline for cross-checking. Both sets of calls are visible in your browser's DevTools > Network tab.

Note: This page may be on a different origin than production (e.g. a Vercel preview URL). eth_accounts returns an empty array when the wallet has not yet granted permission to this origin — this is normal and is not an RPC error. Use "Connect wallet" only if you want to grant permission to this origin; it is not required for the baseline checks.
