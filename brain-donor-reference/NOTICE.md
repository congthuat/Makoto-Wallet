# Notice: archived reference only

This folder is a historical snapshot of an earlier Makoto codebase, kept only as
evidence for past migration work. It is **not compiled, not deployed, and not part
of Makoto Wallet**.

**PenguJar / "Makoto Vault" is retired and unrelated to Makoto Wallet.** Any Vault,
Jar or PenguJar code paths, tests or docs that remain in this archive describe a
separate old project and must not be reintroduced. Makoto Wallet's own contract is
`contracts/src/MakotoPayRequests.sol`.
